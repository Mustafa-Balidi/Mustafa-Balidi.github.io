# Mustafa Balidi — Portfolio

Live at **https://mustafa-balidi.github.io**

A single-file personal portfolio. No build step, no dependencies — everything lives in `index.html`.

## Still to fill in

Open `index.html` and search for `EDIT`. Each marker sits next to something that needs real data:

- Email address (appears twice: the hero button and the contact list)
- LinkedIn URL (twice) — delete both rows if you don't want it
- Phone / WhatsApp row — delete it if you'd rather not publish a number
- `resume.pdf` button — drop a `resume.pdf` next to `index.html`, or delete the button
- **PetHaven** and **Fit** — one or two sentences each, plus the correct tech tags
- **GirlScript Foundation** — the real dates and what you were responsible for
- **Education** — university, degree, years

Every change pushed to `main` redeploys automatically in about a minute.

## Notes

- Dark theme is the default; the toggle in the sidebar remembers the visitor's choice.
- Fonts: Bricolage Grotesque and IBM Plex Sans, loaded from Google Fonts.
- Responsive, keyboard accessible, and respects `prefers-reduced-motion`.
